### Multi-Note Interval Identification

Play three notes. The lowest is the reference; name the interval from it to each of the other notes. This is the direct continuation of the two-note interval exercises — same idea, more notes to name at once. Not chords: no quality is ever named, and any combination of pitches can appear.

Every workshop lesson is three notes. Four notes and five notes are a custom choice only.

**Interval Sets**

- **Consonant core**
- **Add the sixths**
- **Add the sevenths**
- **Add the seconds and tritone**
- **Consonant core, second octave**
- **Add the 13ths**
- **Add the 14ths**
- **Add the 9ths and the tritone**
- **All intervals**

**Playing Modes**

- **Ascending**
- **Descending**
- **Harmonic**
- **Mixed**

**Custom Exercise**

- **Notes** — 3 · 4 · 5, tick one or more. The workshop is 3 notes only; this is the only place 4 and 5 exist.
- **Interval set, playing mode, question count, tempo** — as in the fixed lessons

**Intervals in each set**

| # | Set | Intervals | What's new |
| --- | --- | --- | --- |
| 1 | Consonant core | m3, M3, P4, P5, P8 | — |
| 2 | Add the sixths | + m6, M6 | the 6ths |
| 3 | Add the sevenths | + m7, M7 | the 7ths, so the octave stops being free |
| 4 | Add the seconds and tritone | + m2, M2, TT | all simple, 12 |
| 5 | Consonant core, second octave | m10, M10, P11, P12, P15 | set 1 an octave up |
| 6 | Add the 13ths | + m13, M13 | |
| 7 | Add the 14ths | + m14, M14 | so the compound octave stops being free |
| 8 | Add the 9ths and the tritone | + m9, M9, A11 | all compound, 12 |
| 9 | All intervals | 1–8 combined | 24 |

Sets 1–4 and 5–8 are the same ladder twice: first octave, then the same intervals an octave higher. Set 9 is the union.

**How you answer**

All the intervals are chosen at once, then checked together. One row of buttons per note above the reference, in the order the notes sound: two rows in the workshop, one more row for each extra note you ask for in the custom exercise.

**The more notes, the harder**

Three notes gives two judgments, and each note past three gives one more. The middle one is the hard one: the ear hears the stack as one sonority and the top note as "the top", not as an interval measured from the reference. Harmonic gets hardest the more notes are stacked. Descending is close to unusable past three notes, because the reference arrives last.

**What you see**

Nothing before answering. Afterwards the notes on a single staff, each interval labelled from the reference, and the whole thing replays.

**Notes on the rules**

- The reference is always the lowest note, whichever order the notes sound in. Descending puts it last, which is why it's the hardest of the four playing modes.
- The notes above the reference are different from each other — a doubled pitch isn't something you'd be asked to name twice.
- Compound names are kept: a P12 is answered "Perfect 12th", not "Perfect 5th".
- The octave is a real answer throughout. It only feels easy in set 1, where nothing else could be mistaken for it; from set 3 on, the ear has to reject a M7 below it and a m9 above it, and set 7 does the same job for the compound octave.
- Answers will sometimes look like a chord spelled backwards — m3 + P5 is a major triad. Unavoidable in any set with both thirds and fifths, and harmless, since no quality is ever offered.

**Left to decide**

- 9 sets × 4 modes = 36 lessons, plus the custom exercise. That leaves room for set 9 to stay in.
- The two ladders aren't equally hard: a 9th is a compound 2nd, so sets 5–7 are easier than set 4. Do them first if the seconds feel brutal.

### Chord Identification

Play one chord, identify which one it is. No inversions — every chord is played in root position. Answer buttons name the quality only (Maj, min, 7, m7♭5); the root is different every time and gives no clue.

**Chord Sets**

- **Major and minor triads**
- **Diminished and augmented triads**
- **All triads**
- **Suspended and added-tone chords**
- **Dominant and major sevenths**
- **Minor and minor-major sevenths**
- **All sevenths**
- **All chords**

**Playing Modes**

- **Arpeggio, then block — ascending**
- **Arpeggio, then block — descending**
- **Block**
- **Random** — execution and direction both random

**Custom Exercise**

- **Execution** — arpeggio · arpeggio, then block · block — tick one or any combination
- **Direction** — ascending · descending — tick either or both
- **Chord set, question count, tempo** — as in the fixed lessons

Arpeggio alone lives only in the custom exercise. It's the hardest of the three executions and nothing in the workshop drills it.

**Chords in each set**

| Set | Chords |
| --- | --- |
| Major and minor triads | maj, min |
| Diminished and augmented triads | dim, aug |
| All triads | maj, min, dim, aug |
| Suspended and added-tone | sus2, sus4, 6, m6 |
| Dominant and major sevenths | 7, maj7 |
| Minor and minor-major sevenths | m7, m-maj7 |
| All sevenths | 7, maj7, m7, m-maj7, m7♭5, dim7, maj7♯5 |
| All chords | everything above |

**Order of drills**

One contrastive pair at a time first — maj/min, dim/aug, 7/maj7, m7/m-maj7 — then the full set once you can tell the pair members apart. Triads before sevenths, sus and added tones before sevenths, all-sevenths and all-chords last.

**What the playing modes mean**

Two steps, easy to hard. You hear the arpeggio and then the block, which confirms what you just heard; then the block on its own, where the chord has to be recognised without the arpeggio to lean on. **Random** mixes both executions and both directions from question to question, and closes every chord set.

**Notes on the rules**

- Descending is never an inversion: C major played G4→E4→C4 still has the root lowest, so it is still root position. Descending is just harder, since you build the chord upside down and on a seventh chord the 7th arrives first instead of last.
